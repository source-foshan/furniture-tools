Privacy

Privacy policy for Source Foshan Furniture Tools

This policy covers tools.sourcefoshan.com: the MCP server for AI assistants, the JSON API and the embeddable website widgets for the furniture HS code finder and the CBM calculator. Last updated 26 November 2026.

In short

  • No accounts, no sign-in and no API keys.
  • No cookies, analytics or advertising trackers on tools.sourcefoshan.com or in the widgets.
  • We don’t store what you send us. Our hosting provider keeps short-lived request logs for up to 7 days.
  • We don’t sell data or share it with advertisers.

What we receive and why

  • HS code finder (API, MCP tool and widget): the product description or code you search for and any category or material filter, used only to return matching codes.
  • CBM calculator (API and MCP tool): carton dimensions, quantities and weights, or the volumes quoted by suppliers, used only to calculate the totals and the container suggestion. The CBM widget does its calculation in the visitor’s browser and sends nothing to our servers.
  • AI assistants (MCP): your assistant sends us the arguments of the tool call, such as the search text or the list of cartons. We don’t receive your conversation, your account details, your files or your assistant’s memory.
  • Technical data: like any website, each request carries your IP address, the name of your browser or client app and, in some cases, the page it came from.

What we keep

The service has no database and does not save the content of requests. Two things exist briefly:

  • Request logs. Cloudflare, which hosts the service, keeps logs of requests for up to 7 days and then deletes them. A log entry can include the time, the address requested (for API calls made with GET this includes the search text or the dimensions), the response status and network details such as the IP address and approximate location. We use these logs only to keep the service running, fix errors and stop abuse.
  • Rate limiting. Your IP address is used to count requests (60 per minute). The counter is held in memory for about a minute and is not stored.

Who else handles the data

Cloudflare, Inc. hosts and runs the service and processes requests on our behalf (Cloudflare privacy policy). We don’t sell or rent data and don’t share it with advertisers or data brokers. We would disclose information only if the law required it.

Links to sourcefoshan.com

Results and widgets include links to sourcefoshan.com. These links carry tags showing that the visit came from these tools and, for widgets, the website the widget is on. sourcefoshan.com receives nothing unless someone follows a link. Once you are on sourcefoshan.com, the sourcefoshan.com privacy policy applies, including its analytics.

Websites that embed a widget

Each widget loads in its own frame from tools.sourcefoshan.com. The embed script passes the website’s domain name to the widget so that the credit link can say where the visit came from. Apart from that, the widget reads nothing from the page it is on and sets no cookies. The owner of that page is responsible for the rest of their page and their own privacy policy.

Your choices and rights

Because there are no accounts and no stored request data, there is usually nothing for us to look up, correct or delete beyond the request logs, which are deleted automatically within 7 days. If you have a question or a request about your data, contact us and we will reply.

Children

These are business tools for furniture importers and are not directed at children.

Changes

If we change how the service handles data, we will update this page and the date at the top.
