CBM & container calculator

Carton sizes in cm or inches give total CBM, cubic feet, air volumetric and chargeable weight and sea LCL revenue tons. Supplier volumes add up what several factories quoted. Both suggest LCL, a 20GP or a 40HQ.

Good to know

  • Works anywhere. WordPress (Custom HTML block), Shopify, Wix and Squarespace (embed code blocks), Webflow or plain HTML. Using both tools on one page? Include the script line once.
  • Keep the credit line. The “by Source Foshan” link under the tool is how it stays free. Please leave it in place.
  • Light and private. The tool loads only when it scrolls into view and sets no cookies. CBM figures are worked out in the visitor’s browser; HS searches go to our API only to return results.
  • Reference figures. CBM results are planning estimates and HS codes are candidates, not a customs ruling. Both tools say so to your visitors.
